# AI Interviewer MVP

A production-ready AI interview platform with 1,500 pre-generated questions across 5 FAANG companies and comprehensive study materials. Evaluates candidate answers using RAG against company-specific context, generates follow-ups via Claude, and produces detailed scored reports.

---

## Prerequisites

- Python 3.11+
- AWS account with Bedrock access enabled for:
  - `anthropic.claude-3-5-haiku-20241022-v1:0`
  - `anthropic.claude-3-5-sonnet-20241022-v2:0`
  - `amazon.titan-embed-text-v2:0`
- AWS account with Amazon Transcribe enabled (for audio input only)

## Setup

### 1. Install dependencies

```bash
cd "c:\AI Interviewer MVP"
pip install -r requirements.txt
```

### 2. Configure AWS credentials

```bash
copy .env.example .env
```

Open `.env` and fill in your values:

```
AWS_ACCESS_KEY_ID=your_key_here
AWS_SECRET_ACCESS_KEY=your_secret_here
AWS_DEFAULT_REGION=us-east-1
BEDROCK_TEXT_INFERENCE_PROFILE_ID=your_inference_profile_id_or_arn
```

All other values have sensible defaults and can be left as-is for the first run.

Important: When using Amazon Nova models, Bedrock on-demand throughput may be unsupported for your account/region. Set `BEDROCK_TEXT_INFERENCE_PROFILE_ID` to a provisioned inference profile ID/ARN that includes your configured Nova model.

### 3. Add your context document

Drop a `.txt`, `.pdf`, or `.docx` file into `data/context/`. A sample transformer-related document is already there for testing.

### 4. Add your questions file

Create `data/questions/{context_name}_questions.json` following this schema:

```json
{
  "context_name": "my_context",
  "topics": [
    {
      "topic_id": "topic_001",
      "topic_label": "Topic Display Name",
      "seed_question": "Your interview question here?"
    }
  ]
}
```

**Note:** `expected_key_points` are NOT pre-defined. Instead, the evaluator derives key points dynamically from the RAG-retrieved context chunks for each answer. This allows the system to work with any context document without manual key point curation.

A sample file `data/questions/faang_context_questions.json` with 12 FAANG interview topics is already provided.

### 5. Ingest the context document

```bash
python -m scripts.ingest --context data/context/sample.txt
```

Re-running this command is safe — already-indexed chunks are skipped automatically.

```
Loading sample.txt...
  → 8 chunks. Embedding new chunks only...
  → 8 inserted, 0 skipped (already cached). Done.
```

## How the interview works

1. **Start** — Click "Start Interview". The first seed question is served immediately (no LLM call).
2. **Answer** — Type your answer or hold the mic button to speak (audio is transcribed in real time via AWS Transcribe).
3. **Evaluation** — AWS Bedrock (Claude Haiku) scores your answer 0–1 by comparing it against RAG-retrieved context chunks (no pre-defined expected key points).
4. **Follow-up logic:**
   - Score **> 0.8** → move to next topic
   - Score **0.4 – 0.8** → generate a follow-up question (up to 3 questions per topic)
   - Score **< 0.4** → mark as incorrect, move to next topic
5. **Report** — After all topics are done you are redirected to the report page showing overall grade, per-topic scores, strengths, gaps, and a narrative generated by Claude Sonnet.

## Using your own content

1. Drop your document in `data/context/my_doc.pdf`
2. Create `data/questions/my_doc_questions.json` (the stem must match)
3. Ingest: `python -m scripts.ingest --context data/context/my_doc.pdf`
4. In `ui/templates/index.html`, change `window.CONTEXT_NAME = "my_doc";`
5. Restart the server

```
├── api/           FastAPI app, routes, WebSocket handler
├── core/          Interview orchestrator, evaluator, follow-up logic, scorer, reporter
│   └── llm_client.py    Centralized Bedrock invocation + audit logging (new)
├── data/
│   ├── context/   Drop context documents here
│   └── questions/ Drop seed_questions.json files here
├── db/            SQLite models (SQLAlchemy), async CRUD + generic helpers
├── models/        Pydantic request/response schemas
├── rag/           Chunker, Titan embeddings, ChromaDB, retriever
├── scripts/       ingest.py — one-time document ingestion CLI
├── ui/            Jinja2 HTML templates + vanilla JS + CSS
└── config/        Settings (pydantic-settings), AWS boto3 client factory
```
